# EJERCICIOS-EXPOSICIONES-GRUPALES

Ejercicios realizados en clases por grupos y exposiciones (Estructura de Datos, C++).

| Carpeta | Tema | Función agregada |
|---|---|---|
| `Grupo_1_Lista_Doble` | Lista doblemente enlazada | `invertir()`: invierte el orden de los nodos cambiando los punteros |
| `Grupo_2_Lista_Doble_Circular` | Lista doble circular (plantilla) | `obtenerEnPosicion(int pos)`: devuelve el dato en la posición `pos` (desde 0) |
| `Grupo_3_Pila` | Pila de personas (con nodos) | `sizePila()`: devuelve el número de elementos de la pila |
| `Grupo_4_Cola` | Cola (FIFO) | `contarElementos()`: devuelve el número de elementos de la cola |
| `Grupo_5_Notaciones` | Infija, postfija y prefija | `contarOperadores()`: cuenta los operadores `+ - * / ^` de una expresión infija |
| `Grupo_6_Pila` | Pila con recursividad | `sumar()`: suma recursivamente los elementos de la pila |

## Cómo compilar y ejecutar

Desde la carpeta de cada grupo:

```bash
g++ *.cpp -o program.exe
./program.exe
```
